结论抢答：一半以上只是粗细差（齿轮/回形针/复制/垃圾桶…），换了肉眼难分辨；
真正有「换脸」感的是 发送（纸飞机）、新建会话（方框笔）、重新生成（逆时针箭头） 这几个。
风险提醒：这些图标在宿主里全是哈希类名锚点，宿主一升级可能错位——换越多维护面越大。
