增强提示词 · 交互稿

模拟链路：点魔法棒 → 转圈（可点取消）→ 文本替换、按钮变撤销 → 撤销复原 / 手改一字撤销消失
状态：空闲 空闲 增强中 可撤销
增强失败：网络超时（示意），原文已保留
这版交互稿定的规则（照 WorkBuddy 实测逻辑）
1. 出现条件：输入框有文本（≥1 字）时魔法棒才可点；空输入禁用。
2. 增强中：图标变转圈，tooltip 显示「增强中…」；再点一次 = 取消，原文立即恢复。
3. 增强完成：全文替换为增强结果（输入框闪一下淡绿提示），按钮变成绿色撤销箭头；tooltip「撤销增强」。
4. 撤销消失条件：增强后你手动改过任意字符 → 撤销钮自动退掉（WorkBuddy 的 before/after diff 逻辑）。
5. 失败：红字提示，输入框保持原文不变。
6. 按钮位置：发送钮左侧（WorkBuddy 同位），ghost 圆形图标钮，不动现有工具栏布局。
7. 本稿里「增强结果」是本地模拟的；真实现走 ctx.llm.prepareCall + WB 同款 system/user 双 prompt，模型路由用当前会话模型。
