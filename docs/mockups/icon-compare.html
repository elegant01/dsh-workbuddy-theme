工具行图标对照

左列 = DSH 现状（自绘 dsw-icon，16px、描边 1）；右列 = WorkBuddy 实际用的 lucide 图标（24 视框、描边 2、圆头）。
两边 SVG 均从各自安装包原样抽出；WB 侧的分组映射量自其 getToolIconByName 配置表。
工具DSH 现状WorkBuddy
执行命令（bash）
DSH 用 >_ 提示符；WB 用带窗口的终端
 api-outline square-terminal
读文件（read）
DSH 是眼睛；WB 是文档
 browse-outline file-text
写 / 改文件（write/edit）
都是笔，WB 带文档底
 edit-outline file-pen
搜索（grep/glob/search）
都是放大镜，粗细不同
 search-outline search
网页（web_search）
都是地球仪
 globe-outline globe
代码 / 终端（code/terminal_*）
DSH 尖括号；WB >_ 黑框
 code-outline terminal
其他工具（others）
DSH 星星；WB 待办清单
 sparkle list-todo
直觉差异：DSH 这套偏细、偏「符号」（>_/眼睛/尖括号），WorkBuddy 偏粗、偏「物件」（终端窗口/文档/清单）。
换法与模型品牌图标相同：CSS mask 罩到 [data-variant] 行上，颜色跟随 currentColor，不动宿主 DOM。
